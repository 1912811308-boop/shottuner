# 固定测试图集（跨端对齐用）

> 由 `tools/fixtures/gen_frame_stats_fixtures.py` 生成，**请不要手工改这些 PNG** —— 要改就改脚本并重新生成。

## 为什么是合成的

- **可控**：每张图的亮度分布写死在脚本里（真拍做不到「过曝区恰好占 44%」）
- **可再生**：任何人重跑脚本都得到逐字节相同的图 —— 真拍照片重拍就不是同一批了，跨端比对立刻失去意义
- **小**：单张 < 200KB，整体 < 1.5MB
- **无隐私**：不含任何真人物

## ★ 为什么是 PNG 而不是 JPEG

JPEG 有损解码会因平台实现不同产生差异，那是**解码器差异**而不是**算法差异**，会把问题搅浑。架构文档 T12 的定位顺序第一条就是这个：先用无损 PNG 重跑，若差异消失则是 JPEG 解码差异（可接受，调阈值即可）。

## 尺寸与格式

- 320x240，8 位 RGB，无交错，无 alpha
- 读法：Android 侧 `analysis/PngDecoder.kt`；iOS 侧用 CoreGraphics

## 每张图要触发什么

| 文件 | 预期特征 | 为什么需要它 |
|---|---|---|
| `01-bright.png` | 均匀亮场景 | 均匀亮场景。全画面高亮度但不溢出（无 clipHigh），用于测曝光维度的高档区间。 |
| `02-dark.png` | 均匀暗场景 | 均匀暗场景。低亮度但不欠曝（无 clipLow），用于测曝光维度的低档区间。 |
| `03-overexposed.png` | 过曝 | 过曝。中心一大片纯白（占画面约 44%），触发 clipHigh 统计。 |
| `04-underexposed.png` | 欠曝 | 欠曝。中心一大片纯黑（占画面约 44%），触发 clipLow 统计。 |
| `05-with-face.png` | 有人脸 | 有人脸。中心肤色椭圆（skinRatio 显著），背景偏冷 —— 用于测肤色占比与场景分类的人像分支。 |
| `06-no-face.png` | 无人脸 | 无人脸。冷绿调渐变，**不含任何肤色像素** —— 与 05 对照，确保 skinRatio 分支真的被区分开。 |
| `07-high-texture.png` | 高纹理 | 高纹理。2 像素棋盘 → 拉普拉斯方差极大，用于测清晰维度的上限区间。 |
| `08-low-texture.png` | 低纹理 | 低纹理。模糊后的平滑渐变 → 拉普拉斯方差很小，用于测清晰维度的下限区间。 |

## 用法约定

- **T13 验收①**：两端读**同一批图** → 各自算 `FrameStats` → 四维分**逐分相同**（不是「接近」，是相同 —— 因为算法是同一份 common 代码）
