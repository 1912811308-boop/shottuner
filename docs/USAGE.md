# 光影调参 · 使用卡

一句话：它是**测光仪 + 构图教练 + 录像方案 + 模式顾问**，不拍照。拍照用系统相机，参数照着抄。

底部三个页签各管一件事：**照片**（拨多少）、**录像**（怎么录）、**功能**（该不该换模式）。

## 五步（拍照）

1. 打开「光影调参」，允许相机权限。屏幕顶部的场景名和底部的三个数字就是全部输出。
2. 对着你要拍的画面**停两秒**，等数字不再跳动、构图分出现。
3. 抄下三个数：ISO、快门、色温。忘了就点「复制参数」进剪贴板。
4. 切到小米相机 → 顶部模式栏滑到「专业」→ 拨 ISO / S / WB 三个盘。
5. 拍。光线变了（换房间、进阴影、太阳落下去）就回来再测一次。

## 拨盘对应

| App 上的数 | 小米专业模式里 |
|---|---|
| 感光度 400 | ISO 盘，选 400 |
| 快门 1/60 | S 盘，选 1/60（等于六十分之一秒） |
| 色温 4600K | WB 盘，拖到 4600；不确定就用 A |
| 偏差 -0.7 | 不用拨。手动的 ISO+快门锁死后 EV 失效，这列只是告诉你画面偏亮还是偏暗 |

相机设置里把「参考线」打开，九宫格常驻，比每次回来 App 里看构图更省事。

## 三种常见场景（14 Pro 参考值）

| 场景 | ISO | 快门 | 色温 | 为什么 |
|---|---|---|---|---|
| 白天风景 | 50–100 | 1/500–1/1000 | 5500 或 A | 光够就别抬 ISO，细节全靠低感光度 |
| 室内人像 | 400–800 | 1/125 | 按现场光测出的值锁死 | 快门先保证脸不糊，亮度靠 ISO 补 |
| 夜景街拍 | 800–1600 | 1/30 | 3000–3800 | 宁可 ISO 高一点也不要快门慢过 1/25，糊了没法救 |

## 录像怎么设

切到「录像」页 → 先选一个拍摄意图（走动跟拍 / 口播讲解 / 运动抓拍 / 暗光现场 / 风光运镜 / 慢动作 / 延时 / 翻拍文档），页面会给出完整方案。四个数最重要：分辨率、帧率、快门、防抖。

**1. 快门不能随便动，它由帧率决定。** 行规叫 180 度快门：

| 帧率 | 快门 | 为什么 |
|---|---|---|
| 30fps | 1/60 | 通用档，暗光最稳 |
| 60fps | 1/120 | 走动、运动，后期能慢放一半 |
| 120fps | 1/250 | 慢动作专用，室内基本拍不了 |
| 24fps | 1/50 | 最像电影，口播新手别用 |

违反这条，运动物体会出现频闪和抖动感。**想让画面变暗，应该加 ND 减光镜，不是拨快门。**

**2. 分辨率默认 1080P，不是 4K。** 1080P 防抖裁切后仍清晰、文件小三倍、暗光更干净。只有需要后期裁切或投影时才用 4K。

**3. 防抖不是永远开着好。** 走动跟拍开最强档；固定机位（三脚架、靠墙）必须关掉，否则画面会缓慢漂移；暗光下也别用最强档，它裁切更多、噪点更明显。

**4. LOG 只在打算后期调色时开。** 直出会发灰发平；8bit 机器开 LOG 会有色带；弱光下开 LOG 噪点更明显。

## 功能页怎么用

切到「功能」，它会告诉你这会儿该开什么模式，每条都带原因和入口路径。语气分三种：

- **该用**（绿色）：比如弱光静止 → 开手持夜景
- **别用**（橙色）：比如弱光下有运动 → **别用夜景模式**，多帧合成一有运动就拖影
- **知道**（蓝色）：设备能力与常识，比如长焦的传感器面积只有主摄的 30%，弱光下别切

页面标题那一行还会显示 AI 看到了什么，比如「AI 看到 天空 山脉 云」。

## 技法页怎么用

切到「技法」，它会按当前对着的画面挑三条最该注意的，不是把所有条目糊上来：

- 每张卡四行：分类与标题 / 一句话口诀 / 起手参数 / 命中原因
- 点开任意一张，是完整动作分解：什么时候用、怎么做（编号步骤）、为什么、常见错误、拍完怎么验
- 上面一排分类胶囊，选一个就只看那一类（人像是 7 条，风光 6 条，夜景 4 条……）
- 还没对准画面时显示「新手起步包」，给的是基本功那三条

三个使用建议：先在照片页把数拨好，再来技法页看动作；同一条技法反复出现，说明这就是你当前场景的主要矛盾；「为什么」那一段别跳过，知道原理才能迁移到下一种光。

## AI 判定的可信度

场景标签后面会注明来源：

- `人像 92% · AI·人脸` —— 检出人脸，最可靠
- `风景 93% · AI·标签` —— 打标认出天空/山脉/沙滩，也可靠
- `逆光 78% · 规则` —— 靠亮度直方图判断，逆光场景规则比 AI 准

AI 用的是降采样后的小图，判大类（人像/风景/食物/宠物/建筑）没问题，但不认具体是谁、也不做面部细节。

## 想让建议直接浮在相机上

1. 应用底部点「在系统相机上浮一个建议卡」。
2. 第一次会跳到系统设置，打开「显示在其他应用上层 / 悬浮窗」，返回再点一次。
3. 系统弹「将开始截取您的屏幕」，点「立即开始」。应用会自动退到后台。
4. 打开小米相机，屏幕上方出现一张卡：场景 · `ISO · 快门 · 色温` · 一句构图建议。
5. 卡片可以上下拖，别挡快门。点卡片上的「停」就关掉。

三条限制：只能提示、不能替你拨；画面到建议有 100–300ms 延迟，摇镜时跟不上；每次启动都要重新确认一次录屏，通知栏会常驻一条「正在录制或投放」。

如果卡片上的数字一直不动，说明你的系统把相机预览放进了受保护图层，录屏抓到的是黑屏。这种情况告诉我，我换方案。

## 三条红线

1. **ISO 别过 1600**。14 Pro 主摄到 3200 噪点肉眼可见，宁可放慢快门或找支撑。
2. **快门别慢过 1/25**。手持极限，低于这个数必须靠墙、靠着栏杆或上脚架。
3. **宁可略暗，不要过曝**。暗部后期能提，高光溢出救不回来。

## 构图怎么练

打开 App 的网格，看三样东西：

- 青圈是你的主体，白色虚线圈是最近的三分交点。两个圈不重合，就挪手机让它俩对齐。
- 绿色横线是水平，橙色虚线是你画面里真实的地平线。两条不重合就是歪了，转手机对齐。
- 构图分上不去先看建议那一行，它会给原因，比如「地平线横在正中间会显得呆板」。

前两周刻意只用一种构图法（比如只用三分法），练到不用看线也能摆对，再换下一种。
